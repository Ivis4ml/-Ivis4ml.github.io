# 万神殿 · Pantheon, Roma — 1:1 实时程序化重建

纯 Three.js（r186，已 vendor 在 `vendor/`，**无任何外部资产、无构建步骤**）。所有几何与贴图都是代码生成的，
按真实尺寸建模（1 单位 = 1 米）。直接用任意静态服务器打开 `index.html` 即可：

```bash
cd pantheon && python3 -m http.server 8000     # → http://localhost:8000
```

ES module + importmap，需要 http(s) 访问，不能用 `file://`。GitHub Pages 开箱即用（全部为相对路径）。

## 看什么

| | |
|---|---|
| **▶ 漫游** | 3.5 分钟电影式运镜：黎明航拍 → 广场 → 柱廊 → 青铜门 → 圆厅 → 眼窗光斑扫过 → 穹顶之上 → 黄昏 → 夜。触碰画面即接管相机 |
| **环绕 / 步行** | 环绕：拖动旋转、滚轮缩放、右键平移。步行：WASD / 方向键、Shift 奔跑、拖动看向（带碰撞：柱子、喷泉、墙；触屏有虚拟摇杆） |
| **时间 / 日期** | 太阳位置按罗马纬度（41.8986°N）、日期与太阳时**真实解算**；眼窗光斑落点由阴影贴图决定（信息面板里会读出它落在哪面墙/地面）。预设：春分、**罗马生日 4/21**、夏至、秋分、冬至 |
| **天气** | 晴 / 多云 / 阴 / 雨。雨只会通过 Ø8.92 m 的眼窗落进圆厅，地面积水反光 |
| **📷 / 🌐** | 截图；**导出 360° 全景图**（6 面 → 2:1 等距柱状 JPEG，可直接丢进 VR 查看器 / 街景） |
| **🔊** | 程序合成的声场：广场人声、喷泉、雨燕、风、雨，以及站到穹顶下时 ≈6.5 s 的卷积混响，脚步声随地面材质变化 |

快捷键：`T` 重启漫游 · `H` 隐藏界面 · 步行模式 `WASD`。

URL 参数：`?q=low|med|high` 画质 · `?t=17.5&d=172` 太阳时 / 年积日 · `?w=rain` 天气 · `?view=oculus` 起始视角（`piazza facade nave rotunda oculus apse aerial dome`）· `?pano=1` 加载后自动导出全景。

| 项目 | 真实 | 模型 |

| 眼窗直径 | 8.92 m | 8.92 m，带青铜内衬环 |
| 藻井 | 5 圈 × 28 个，三级退台 | 5 × 28，真实三级凹进几何 + 镀金青铜玫瑰花饰；越往上越小 |
| 穹顶厚度 | 眼窗处 1.2 m → 拱脚 ≈6 m | 外壳为同心球 R+1.2 m，下接 7 道砖砌台阶环 |
| 前廊 | 16 根埃及花岗岩柱（前排 8 + 后 2 组×4），柱高 ≈14 m | 16 根，14 m（柱础 0.57 + 柱身 11.88 + 科林斯柱头 1.55），柱身带收分；少数红色花岗岩替换柱 |
| 额枋铭文 | M·AGRIPPA·L·F·COS·TERTIVM·FECIT | 同文，刻在檐壁上；檐口含齿饰、山花、斜檐 |

| 圆厅壁龛 | 8 个（入口 + 主龛 + 6 个半圆/矩形龛），每个 2 柱 | 同，另有 8 座带三角/弧形山花的壁柱龛 |
| 地面 | 方与圆的拼花石材，中间微凸 | 13×13 方阵拼花（斑岩、黄大理石、花岗岩），0.3 m 凸起 |
| 外观 | 砖砌鼓座，三道檐口，七道台阶环，铅皮穹顶 | 同；鼓座带减压拱纹样，铅皮分缝 |
| 广场 | 1575 年喷泉 + 1711 年拉美西斯二世方尖碑（6.34 m） | 同，含八角水池、岩座、海豚与动态水柱 |

**近似之处**（诚实说明）：石材/砖/大理石是程序纹理而非照片；山花的青铜浮雕已佚故留白；街区由 BSP 生成，
并非测绘数据；圣彼得大教堂、祖国祭坛、巴洛克圆顶为简化体量，位置按经纬度换算。

## 结构

```
src/pantheon.js   建筑本体（外观 / 前廊 / 圆厅 / 穹顶）+ InteriorLight（室内 IBL 与范围受限点光源）
src/geo.js        柱身、科林斯柱头、球面藻井等几何生成器
src/textures.js   全部 Canvas2D 程序纹理（罗马砖、石灰华、花岗岩、大理石、拼花地面、鹅卵石…）
src/beam.js       屏幕空间体积光：沿视线步进，逐点判断“朝太阳的射线是否穿过眼窗圆盘”，用场景深度截断
src/sky.js        太阳/月亮位置、Preetham 天空 + 暮光穹顶、星空、雾、天空 IBL
src/world.js      广场、喷泉、BSP 街区（夜间窗户随机亮灯）、遮阳伞、泛光灯、远景地标与山丘
src/life.js       人群（含走进万神殿的访客）、雨燕群、喷泉水柱、光柱尘埃、雨
src/camera.js     环绕 / 步行（碰撞）/ 漫游关键帧 / 平滑飞行
src/audio.js      WebAudio 程序化声场
```

渲染：HalfFloat HDR + 4× MSAA → 体积光 → Bloom → ACES；自适应曝光（室内外、昼夜）；
4096² 方向光阴影；动态分辨率保帧率。典型一帧 ≈ 1.0 M 三角形 / ≈ 450 次绘制（含阴影 pass）。
