# 万神殿 · Pantheon, Roma — 1:1 实时程序化重建

纯 Three.js（r186，已 vendor 在 `vendor/`，**无任何外部资产、无构建步骤**）。所有几何与贴图都是代码生成的，
按真实尺寸建模（1 单位 = 1 米）。直接用任意静态服务器打开 `index.html` 即可：

```bash
cd pantheon && python3 -m http.server 8000     # → http://localhost:8000
```

ES module + importmap，需要 http(s) 访问，不能用 `file://`。GitHub Pages 开箱即用（全部为相对路径）。

## 怎么看

没有导览、没有字幕。打开即站在广场上，面朝门廊：

| | |
|---|---|
| **视角（右上三段切换，或键 1/2/3）** | **步行**：站在地面，拖动环顾（拖向哪边就转向哪边），点击地面或滚轮走动，带碰撞（柱子、喷泉、墙）。**环绕**：围着建筑转——拖动旋转，右键 / Shift 拖动平移，滚轮缩放。**自由**：自由相机，WASD 沿视线飞行，Q/E 升降，滚轮前进后退，Shift 加速，右键拖动横移，无碰撞，可穿进任何位置 |
| **切换不丢位置** | 环绕 ↔ 自由瞬间切换、视点不变；在环绕 / 自由中**双击地面**落到该点站立；Ctrl + 滚轮 = 镜头变焦 |
| **进入** | 走进青铜门即进入圆厅；抬头看眼窗，光斑随时间在墙面上移动 |
| **时间** | 左下滑条；▶ 让时间流动。太阳位置按罗马纬度（41.8986°N）、日期与太阳时**真实解算**，眼窗光斑落点由阴影贴图决定 |
| **设置** | 地点（广场/门廊/圆厅/眼窗下）、日期（春分、罗马生日 4/21、夏至、秋分、冬至）、天气（晴/多云/阴/雨，雨只经 Ø8.92 m 眼窗落入）、画质、声音、截图、360° 全景图导出 |

界面只在相关时给一行提示（每条只出现一次）。

URL 参数：`?q=low|med|high` · `?t=17.5&d=172` 太阳时 / 年积日 · `?w=rain` · `?view=piazza|portico|rotunda|oculus` · `?pano=1` 加载后导出 2:1 等距柱状全景。

## 材质（粗糙、有颗粒）

石材不是光滑 PBR 色块，而是三层叠加：

1. **烘焙贴图**（`textures.js`）：Canvas2D 生成颜色 + 切线空间法线 + 粗糙度三张图；石灰华带孔洞与层理，花岗岩为 Worley 矿物晶粒（长石/石英/云母），大理石带风化壳与污渍，罗马砖有灰缝与不规则烧结色差。
2. **世界空间三平面细节**（`detail.js`）：以 `onBeforeCompile` 注入两个尺度的高频噪声，扰动反照率、法线与粗糙度，并叠加低频 `macro` 变化以消除可见重复。
3. **全部非金属**：石材 roughness 0.75–1.0、metalness 0；铅皮穹顶与青铜仅用低金属度 + 粗糙度图。末端 `GradePass` 做轻微暖色分级，避免“CG 蓝阴影”。

## 室内

`interior.js`：按实际建筑秩序建造——下层 8 个壁龛（入口与主龛在轴线上以大拱穿过檐部，其余 6 个半圆/矩形交替），墩面为分格大理石，每墩一座带山花的 aedicule，龛口成对柱与壁柱；整圈檐部（楣梁、檐壁、带齿饰的檐口）；阁楼层 32 个壁柱开间的盲窗大理石板；穹顶 5 × 28 个三级退台藻井（镀金花饰已佚，故留素面）；地面为方圆拼花（中间微凸、含排水孔）；青铜门及厚墙门洞；墓前鲜花与座椅。光照用 PMREM 室内 IBL 与范围受限的点光源，光柱为屏幕空间体积光。

## 周边街区

`city.js` + `facades.js`：街区为**封闭实体**（四壁 + 屋顶 + 山墙，正确缠绕，无穿帮），按罗马的 palazzo 形制组织——沿街连续立面、3.4 m 开间、一层商铺（3 种）+ 上层窗（3 种）、赭/橙/黄灰泥色板、百叶窗、屋顶瓦片与烟囱；立面贴图为小尺寸平铺单元（非整面大贴图），夜间窗户由哈希着色器随机亮灯。街道为 BSP 划分，并非测绘数据。

| 项目 | 真实 | 模型 |

| 眼窗直径 | 8.92 m | 8.92 m，带青铜内衬环 |

| 穹顶厚度 | 眼窗处 1.2 m → 拱脚 ≈6 m | 外壳为同心球 R+1.2 m，下接 7 道砖砌台阶环 |
| 前廊 | 16 根埃及花岗岩柱（前排 8 + 后 2 组×4），柱高 ≈14 m | 16 根，14 m（柱础 0.57 + 柱身 11.88 + 科林斯柱头 1.55），柱身带收分；少数红色花岗岩替换柱 |

| 地面 | 方与圆的拼花石材，中间微凸 | 13×13 方阵拼花（斑岩、黄大理石、花岗岩），0.3 m 凸起 |

| 广场 | 1575 年喷泉 + 1711 年拉美西斯二世方尖碑（6.34 m） | 同，含八角水池、岩座与动态水柱 |

**近似之处**（诚实说明）：石材/砖/大理石是程序纹理（颗粒与粗糙度来自噪声与晶粒模型）而非照片；山花的青铜浮雕已佚故留白；街区由 BSP 生成，
并非测绘数据；圣彼得大教堂、祖国祭坛、巴洛克圆顶为简化体量，位置按经纬度换算。

## 结构

```
src/pantheon.js   建筑本体（外观 / 前廊 / 圆厅 / 穹顶）+ InteriorLight（室内 IBL 与范围受限点光源）
src/geo.js        柱身、科林斯柱头、球面藻井等几何生成器
src/textures.js   全部 Canvas2D 程序纹理（颜色 + 法线 + 粗糙度）
src/beam.js       屏幕空间体积光：沿视线步进，逐点判断“朝太阳的射线是否穿过眼窗圆盘”，用场景深度截断
src/sky.js        太阳/月亮位置、Preetham 天空 + 暮光穹顶、星空、雾、天空 IBL
src/world.js      广场、喷泉、遮阳伞、泛光灯、远景地标与山丘
src/life.js       人群（含走进万神殿的访客）、雨燕群、喷泉水柱、光柱尘埃、雨
src/camera.js     街景视角（拖动环顾、点击行走、碰撞、变焦）/ 鸟瞰升降
src/detail.js     世界空间三平面细节着色器注入
src/grade.js      后期分级 pass
src/city.js       周边街区生成（封闭实体、沿街连续立面）
src/facades.js    立面 / 屋顶小尺寸平铺贴图
src/interior.js   圆厅室内建筑细节
src/audio.js      WebAudio 程序化声场
```

渲染：HalfFloat HDR + 4× MSAA → 体积光 → Bloom → ACES；自适应曝光（室内外、昼夜）；
4096² 方向光阴影；动态分辨率保帧率。典型一帧 ≈ 1.0 M 三角形 / ≈ 450 次绘制（含阴影 pass）。
