# 看不见的故障 · 横线本上的铅笔动画

一部约 3 分钟的逐帧"手绘"动画，画在一本横线笔记本里：2024 年一次反复中断的模型训练、一行被改动的底层库、
一座总出现在生成图背景里的城市，以及奖杯之外的公开回应、访谈与诉讼。

**没有一张图片素材。** 纸张、每一根铅笔线、每一片排线、每一次线条抖动，都由 Canvas 2D 在浏览器里实时程序化画出。
直接打开 `index.html` 即可（`file://` 也能用，经典 `<script>`，无构建步骤）；GitHub Pages 开箱即用。

```bash
cd invisible-fault && python3 -m http.server 8000     # → http://localhost:8000
```

URL 参数：`?t=秒` 跳到某一时刻 · `?autoplay=1` · `?hq=1` 强制 1920×1080 渲染（默认按屏幕尺寸降到 0.75 / 0.5 倍以保证流畅）。

## 画法

`src/engine.js` 是一支"铅笔"：

- **笔触**：每一笔先 Catmull-Rom 平滑、按弧长重采样，再叠加低频摆动 + 高频颤动；宽度按压感曲线变化（入笔轻、中段实、出笔尖），
  画成填充的变宽带状多边形，中段再压一遍更实的芯。端点随机出头或回缩（转角处线条交叉 = overdrawn corners），
  长线偶尔断笔，偶尔有一道重描；椭圆是开放轮廓（留缺口）。
- **排线**：任意多边形（偶奇规则，可挖洞）上的扫描线求交，切成 50~140 px 的短笔，带手腕的轻微弧度和参差的起止；
  多层角度 = 交叉排线。光源（屏幕、窗、聚光灯）是排线里挖掉的圆，每加一层挖得更大，所以亮处是"纸本身的光"。
  大面积排线批进一个 `Path2D` 一次描边。
- **line boil**：所有随机数以"笔画 id × 当前重画帧"为种子，每秒 8 次重画；画面本身也按 8 次 / 秒更新（相当于"一拍三"），
  只有翻页转场是 24 帧。
- **遮挡**：没有图层，只有一张石墨层。先画的东西被后画的剪影"擦白"（`knock`），跟画家留白一样；
  逐笔显现时，擦白也只在笔尖走到那里时才发生。
- **逐笔显现**：每个镜头先跑一遍"量长度"，再按累计笔画长度在给定时间内一笔一笔画出来（排线权重更低，画得快）。
- **纸**：米白底 + 低频泛黄与暗角 + 全分辨率纤维噪声 + 印刷蓝横线 + 红色边线 + 淡淡的橡皮擦痕；双页版本带书脊阴影和横线弯曲。
  石墨层最后被一张纸纹颗粒蒙版 `destination-out`（纸的凹处吃不上铅），再以 `multiply` 叠到纸上，彩铅叠色像真的颜料。
- **字**：三种手写体按人分色——旁白和她的话是软灰石墨（龙藏体），他的话是红棕（马善政楷书），标签用霞鹜文楷。
  字体只包含片中用到的字形（`tools/fonts.mjs` 从源码收集字符，向 Google Fonts 请求子集，三个文件共约 370 KB，页面说明文字也计入）。
  每个字有固定的轻微倾斜和抖动，书写时按斜向扫开的遮罩逐字出现。

`src/renderer.js` 是时间轴与合成（纸 → 石墨层 → 纸纹咬合 → 正片叠底，以及翻页、擦除转场），
`src/props.js` 道具，`src/characters.js` 角色（3/4 侧面、背影、俯视；表情只靠眉、嘴角和姿态），`src/act1.js`~`act3.js` 是 23 个镜头。

## 导出视频

```bash
node tools/render.mjs out.mp4 --workers 4              # 1920×1080，H.264 CRF 27（约 80~100 MB：排线每秒重抖 8 次，很吃码率）
node tools/render.mjs out.mp4 --size 1280x720 --crf 28 # 更小的网页版
node tools/render.mjs part.mp4 --from 60 --to 75       # 只导出一段
```

无头 Chromium 逐帧调用 `index.html?render=1` 的 `__frame(T)`，JPEG 管道送进 ffmpeg；相同的"画"（同一个 1/8 秒内）只渲染一次；
分段并行后无损拼接。需要 `playwright`（含 Chromium）和 `ffmpeg`。
